# Simple Banking App

A simple console-based banking application built with Python.

This project allows users to manage their bank balance and basic KYC information through a simple menu-driven interface.

## Features

- Check current balance
- Deposit money
- Withdraw money
- Prevent withdrawals when the balance is insufficient
- Prevent invalid negative deposits/withdrawals
- Check KYC details
- Add and update KYC documents
- Quit the application

## How It Works

When the program starts, it displays a menu:

```text
1. Check your balance
2. Deposit an amount
3. Withdraw an amount
4. Check KYC
5. Update KYC
6. Quit
````

The user can select an option by entering a number from `1` to `6`.

## How to Run

1. Make sure Python is installed on your computer.
2. Clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python simple_banking_app.py
```
